# 180 秒产品操作演示

[在线播放](https://radar.poiuyjie.online/demo/alpharadar-demo-180s.mp4) · [仓库视频文件](alpharadar-demo-180s.mp4)

无配音、无背景音乐，由真实浏览器操作录制、补录并剪辑。独立数据库运行，不修改线上任务；真实接口与应用自带的异常注入共同展示，页面保留数据来源、回退及模拟标识。录制时关闭自动调度，使用「立即巡检」控制演示节奏。

| 时间 | 流程 |
| --- | --- |
| 00:00–00:15 | 总览、搜索与任务状态 |
| 00:15–00:48 | 自然语言、Jev 合规检查、组合规则与确认启动 |
| 00:48–01:22 | 立即巡检、逐条件归因、字段级原始证据 |
| 01:22–01:55 | 修改规则、版本差异、恢复历史版本 |
| 01:55–02:30 | 数据过期与双源冲突的显式降级 |
| 02:30–03:00 | 合规拦截、恢复巡检、执行记录与总览 |

录制脚本为 `frontend/scripts/record-demo.mjs`，仅用于独立演示环境；它会创建任务、修改版本和注入全局异常，不能对生产站点直接运行。依赖 Playwright 和 Chromium，可通过 `PLAYWRIGHT_MODULE`、`BASE_URL`、`DEMO_OUTPUT` 指定环境。原始 WebM 转为 H.264 MP4，成片为 1920×1080、30 fps、180 秒。
